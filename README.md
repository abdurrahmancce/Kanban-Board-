# 🚀 KanbanFlow

A modern and responsive **Kanban Board (Trello Clone Basic)** built using **HTML, CSS, and Vanilla JavaScript**.  
Manage tasks visually with smooth drag-and-drop interactions across **To Do**, **In Progress**, and **Done** columns.

## 🔄 Drag & Drop System

This project uses the native **HTML5 Drag and Drop API**.

### Workflow:
- `dragstart` → Detect selected card
- `dragover` → Allow dropping
- `drop` → Move task to another column
- `dragend` → Cleanup UI states

---

## 💾 Local Storage Support

All tasks are automatically saved in the browser using **localStorage**, so your data remains even after refreshing the page.
